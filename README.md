# Flipper-Zero-Rickroll-bad-usb-Windows
A flipper zero bad usb .txt file that will open edge, create a new tab, load a youtube link, and go full screen.
How to install:
1.Download file to a device with the flipper app
2.If downloaded on mobile sync your flipper with your phone, then go to options/file manager/badusb, the click add new/import
3.If installed on pc open thr flipper app, and plug flipper into pc. from here goto file manager and click SD Card/badusb and drag and drop the .txt file into the folder.
